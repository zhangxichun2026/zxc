SVG 的三种使用方式

同一枚 heart，三种引入方式

① 引用外部图片文件

用 <img> 直接引用本地图片，路径相对于当前 HTML 文件。注意：<img> 内部的 currentColor 不会继承页面颜色，适合固定内容的图片。

<img src="./1.jpg" alt="1.jpg 示例图">

② 直接内联 SVG

把 SVG 代码写进 HTML。可以用 currentColor 继承颜色，也能被 CSS 动画、伪元素和 JavaScript 直接控制。

<svg viewBox="0 0 24 24">…</svg>

③ Lucide 运行时生成

页面里先写占位元素，加载本地的 lucide.min.js 后，createIcons() 会把它替换成真正的 SVG。

<i data-lucide="heart"></i>
