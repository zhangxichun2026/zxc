JavaScript 对象演示

对象是一组"键值对"的集合，像一张学生信息卡：属性名（键）对应属性值，还可以挂上方法。点按钮即可增删改查，控制台同步打印结果。

一、创建对象与访问属性字面量 · 点语法 · 方括号

对象用大括号 { } 创建。属性有两种访问方式：点语法 obj.name 简洁直观；方括号 obj["name"] 适合变量做键名。下面这张"学生卡"就是当前对象。

var zxc_student = {
    zxc_name: "张熙淳",        // 字符串
    zxc_age: 21,               // 数字
    zxc_major: "计算机科学",   // 字符串
    zxc_skills: ["HTML", "CSS", "JavaScript"]   // 数组
};
zxc_student.zxc_name;               // 点语法 → "张熙淳"
zxc_student["zxc_major"];           // 方括号 → "计算机科学"

二、属性的增 · 删 · 改动态添加 · delete · 修改

JavaScript 对象是动态的：随时可以新增属性、修改值、用 delete 删除。填入属性名和值，操作下面这张卡试试。

zxc_student.zxc_hobby = "篮球";      // 新增属性
zxc_student.zxc_age = 22;             // 修改属性
delete zxc_student.zxc_hobby;         // 删除属性
"zxc_hobby" in zxc_student;           // 检查属性是否存在

三、遍历对象与构造函数for-in · Object.keys · new

for-in 逐个访问属性名；Object.keys() 把所有键取成数组。需要批量创建相似对象时，用构造函数 + new 当"模板"。

for (var zxc_key in zxc_student) { /* 遍历所有键 */ }

function zxc_Student(zxc_name, zxc_age) {   // 构造函数
    this.zxc_name = zxc_name;
    this.zxc_age = zxc_age;
}
var zxc_s1 = new zxc_Student("张熙淳", 21);  // new 创建实例

小结：对象 = 属性（描述数据）+ 方法（描述行为）；点语法与方括号等价，键名含变量时只能用方括号； 对象可以随时动态增删改属性；for-in / Object.keys() 用来枚举，构造函数 + new 用来批量造对象—— 掌握这几点，就掌握了 JavaScript 面向对象编程的第一步。
