JavaScript 数组方法可视化演示

一、增删元素push / pop / shift / unshift / splice

push 从尾部加、unshift 从头部加；pop / shift 对应删除；splice 是"万能刀"，可以在任意位置插入或删除。在输入框填个水果名试试。

var zxc_fruits = ["香蕉", "橙子", "苹果", "葡萄", "西瓜"];
zxc_fruits.push("芒果");            // 尾部添加，返回新长度
zxc_fruits.pop();                   // 删除尾部，返回被删元素
zxc_fruits.splice(2, 1, "草莓");    // 从下标2删1个，再插入"草莓"

二、截取 · 合并 · 转字符串slice / concat / join / indexOf

这组方法不改原数组，只返回新结果：slice 切片，concat 拼接，join 变字符串，indexOf 查位置。切下的部分会闪黄框展示。

zxc_fruits.slice(1, 3);             // 下标1到3（不含3）→ 新数组
zxc_fruits.concat(["柠檬", "桃子"]); // 合并成新数组
zxc_fruits.join(" · ");             // 用分隔符拼成字符串
zxc_fruits.indexOf("苹果");         // 查下标，找不到返回 -1

三、遍历与加工forEach / map / filter / reduce / find

换一个数字数组：forEach 逐个访问，map 逐个加工成新数组，filter 按条件筛选，reduce 汇总成一个值，find 找第一个满足条件的。结果以小方块展示。

var zxc_nums = [12, 5, 8, 130, 44, 3];
zxc_nums.map(function (zxc_n) { return zxc_n * 2; });      // 全部×2
zxc_nums.filter(function (zxc_n) { return zxc_n > 10; });  // 筛出大于10
zxc_nums.reduce(function (zxc_a, zxc_b) { return zxc_a + zxc_b; }, 0); // 求和

小结：push/pop/shift/unshift/splice 会修改原数组并多返回被操作元素或新长度； slice/concat/join 不动原数组，返回新数组或字符串； map/filter/find 返回新数组或单个值，forEach/reduce 用来遍历与汇总—— 记住"谁改原数组、谁返回新值"是用好数组的关键。
