一、顺序结构自上而下依次执行

程序默认的执行方式：从第一条语句开始，按书写顺序一条一条执行，不跳过、不重复。

var zxc_a = 1;              // 第 1 步
var zxc_b = 2;              // 第 2 步
var zxc_sum = zxc_a + zxc_b; // 第 3 步 → 3

二、条件结构if / else 与 switch

根据条件是否成立选择不同的执行路径。输入一个成绩（0~100），分别用 if/else if 和 switch 两种写法判断等级。

if (zxc_score >= 90)      { zxc_level = "优秀"; }
else if (zxc_score >= 80) { zxc_level = "良好"; }
else if (zxc_score >= 60) { zxc_level = "及格"; }
else                      { zxc_level = "不及格"; }
等待判断……

三、循环结构for / while / do-while

重复执行一段代码。for 适合已知次数，while 适合先判断再执行，do-while 至少执行一次。

for (var zxc_i = 1; zxc_i <= 9; zxc_i++) { /* 九九乘法表 */ }
var zxc_i = 1, zxc_sum = 0;
while (zxc_i <= 100) { zxc_sum += zxc_i; zxc_i++; }  // 1+2+…+100
do { zxc_count++; } while (zxc_count < 0);           // 条件为假也执行 1 次
点击上方按钮运行循环……

小结：顺序 是默认结构；条件 让程序学会"选择"； 循环 让程序学会"重复"。三种结构组合可以表达任何复杂逻辑—— 这就是结构化程序设计的基础。
