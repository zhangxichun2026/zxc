字体图标的使用方式

一行 class 就能显示图标

① 写 class 引入

在任意元素上添加 fa-solid 加图标名，Font Awesome 的 CSS 会用 ::before 插入对应字形。

<i class="fa-solid fa-heart"></i>

② 用 font-size / color 控制

尺寸走字号，颜色走文字颜色，和其它文本一样参与继承与响应式布局。

.icon { font-size: 28px; color: #2dd4bf; }

③ 层叠组合图标

借助 fa-stack 系列 class，可以把两个图标叠在一起，做出徽章或标记效果。

<span class="fa-stack">…</span>
