提示：String、Number、Boolean、Undefined、Null 是日常最常用的五种原始类型； Symbol 是 ES6 引入的原始类型，每次调用都生成唯一值，常用来做对象属性的“私有键”。 另外，typeof null 会返回 "object"，这是 JavaScript 诞生初期留下的历史遗留问题， 但 null 本身依然属于基本数据类型。对象（Object）属于引用类型，本页不作演示。
